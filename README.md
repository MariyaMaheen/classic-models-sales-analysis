# Classic Models Sales Analysis Dashboard

An interactive **Power BI dashboard** built with the Classic Models
sample database to explore sales performance, order activity, product
demand, and business trends.

> **Project status:** Portfolio project in progress. Update the insights
> and screenshot sections after validating the final dashboard.

## Project Objectives

-   Monitor key sales and order-performance metrics.
-   Explore sales patterns across time, products, customers, and
    regions.
-   Make it easier to identify high-performing areas and potential
    opportunities.
-   Present business information in an interactive, recruiter-friendly
    dashboard.

## Tools and Technologies

-   **Power BI Desktop** --- dashboard development and data
    visualization
-   **Power Query** --- data preparation and transformation
-   **DAX** --- measures and calculated metrics
-   **GitHub** --- project documentation and version control

## Dashboard Features

The dashboard may include the following visuals, depending on the final
version:

-   KPI cards for sales, order quantity, and order activity
-   Sales breakdowns using charts
-   Geographic view of sales
-   Funnel and decomposition-tree analysis
-   Year slicer for interactive filtering

## How to View the Dashboard

1.  Download `Sales_Analysis_Dashboard.pbix` from this repository.
2.  Open it using Microsoft Power BI Desktop.
3.  If Power BI asks for the dataset location, connect it to the
    appropriate Classic Models data source.
4.  Refresh the data if required, then use the visuals and slicers to
    explore the dashboard.
