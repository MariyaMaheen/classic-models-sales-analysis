## 🎯 Project Overview

The **Classic Models Sales Analysis Dashboard** is a Power BI project designed to transform sales data into an interactive visual experience.

The dashboard allows users to explore business performance across multiple dimensions, including product lines, customers, order activity, and geographic regions.

Instead of relying on static reports, users can interact with slicers and visualizations to investigate trends, compare categories, and identify areas that deserve further analysis.

### 🎯 Project Objectives

- Track important sales and order-related KPIs.
- Compare sales performance across product lines.
- Explore customer-level sales contributions.
- Examine geographic patterns in the data.
- Use interactive visualizations to support data-driven decisions.

## 🚀 How to Use

1. **Clone or download the repository.**

   ```bash
   git clone https://github.com/MariyaMaheen/classic-models-sales-analysis.git
   ```

2. Open the project folder on your computer.

3. Open `Sales_Analysis_Dashboard.pbix` using [Microsoft Power BI Desktop](https://www.microsoft.com/en-us/power-platform/products/power-bi/desktop).

4. If prompted, connect the report to the appropriate dataset location.

5. Refresh the data if required.

6. Use the year slicer, charts, and interactive visuals to explore sales performance.

<details>
<summary><b>⚠️ Troubleshooting</b></summary>

- **Dataset not found:** Update the data-source path in Power BI.
- **Visuals not refreshing:** Check the data connection and refresh the report.
- **Dashboard file missing:** Make sure the `.pbix` file has been committed to the repository.
- **Preview not appearing:** Verify that `d1.png` exists at the repository root and that the filename's capitalization matches the image URL.

</details>
