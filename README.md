## 📈 What This Project Covers

| # | Task | Description |
|---|------|-------------|
| 1 | Sales KPI Cards | Display total sales and order-related metrics |
| 2 | Product-Line Analysis | Compare sales across product categories |
| 3 | Customer Analysis | Identify customers contributing to sales |
| 4 | Geographic Analysis | Explore sales distribution across regions |
| 5 | Yearly Filtering | Filter dashboard visuals by year |
| 6 | Sales Breakdown | Analyze sales by product and category |
| 7 | Interactive Visualizations | Explore business performance through Power BI |

## 🚀 How to View the Dashboard

**1. Clone the repository**

```bash
git clone https://github.com/MariyaMaheen/classic-models-sales-analysis.git
cd classic-models-sales-analysis
```

**2. Open the dashboard**

Open `Sales_Analysis_Dashboard.pbix` using [Microsoft Power BI Desktop](https://www.microsoft.com/en-us/power-platform/products/power-bi/desktop).

**3. Connect the dataset**

If prompted, connect to the Classic Models dataset and refresh the data.

**4. Explore**

Use the year slicer and interactive visuals to investigate sales performance.
